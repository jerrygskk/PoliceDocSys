# 公文收發管理系統

> 警察單位公文的 **收文、交辦、陳報、歸檔、列印**，一站完成。

單機桌面程式，不需安裝、不需網路、不需資料庫伺服器——下載後雙擊就能用。專為承辦人員設計，把每天重複的公文流程（編文號、算逾期、改檔名、繕簽收表）交給程式處理。

</p>

`Windows` ・ `免安裝單一執行檔` ・ 目前版本 **v1.2.12**

## 能幫你省下什麼

| 以前怎麼做 | 用這個系統 |
|-----------|-----------|
| 文號用 Excel 手動流水、容易跳號重號 | **文號自動編**，不重不漏 |
| 逐筆翻日期算還剩幾天、哪些逾期了 | **逾期一眼看顏色**（紅＝逾期、橘＝今日到期、綠＝已發文）|
| 掃描的 PDF 一個一個改檔名再歸檔 | **自動比對檔名**，挑對的公文按一下就歸好 |
| 送文本手寫，字醜又易漏 | **簽收單一鍵列印**或存 PDF |
| 在一堆檔案裡翻找某份公文 | **打關鍵字即時搜尋**，不分大小寫 |
| 寫錯、騰錯頁面整筆畫掉 | **資源回收筒可還原**，每天自動備份 |

![資料庫瀏覽，逾期狀態以顏色標示](docs/img/02-browse-overdue.png?v=1.2.7)

> 💡 **逾期狀態怎麼判讀**：紅字＝已超過限辦日期還沒發文；橘字＝今天到期或發文時已逾期；綠字＝已準時發文；無顏色＝還在期限內或免回覆。

## 主要功能

程式開啟後是一排功能分頁，由左至右依序為：

| 功能 | 做什麼 |
|------|--------|
| **交辦單發文** | 把交辦單發出、登錄發文人員與文號，產生發文清單；輸入後忘記按發文會亮出提醒，防止漏發 |
| **交辦單收文** | 登錄收到的交辦單：收文日期、業務組、承辦人、限辦日期 |
| **公文陳報** | 向上陳報公文，分「刑案陳報」與「一般陳報」兩種表單；案件分類支援**俗稱搜尋**——輸入慣用簡稱就帶出正式案類，俗稱可在「資料庫設定 → 案件類型」自行維護 |
| **敘獎登錄** | 登錄敘獎的事由與敘獎人員，可連續輸入並在下方即時預覽；敘獎人員可點右側候選人員名條、下拉選取或直接輸入姓名，名單外姓名也能填。送文者輸入模式下同時填發文日期與發文人員，登錄即完成發文；發文結算模式則兩欄免填，改由「簽收單列印」頁結算 |
| **罰單登錄** | 登錄舉發的罰單：選開立人員後連續輸入罰單編號，一張罰單一位開立人員；編號只收半形英數並自動轉大寫、重複登錄會擋下。本次登錄的清單可即時修改或刪除 |
| **簽收單列印** | 依發文日期產生簽收表（含交辦／刑案／一般／敘獎／罰單），預覽後列印或存成 PDF |
| **資料庫瀏覽** | 一覽全部公文、關鍵字搜尋、依逾期狀態篩選；建錯類別（刑案/一般）可一鍵轉換（僅管理者） |
| **檔案歸檔** | 把掃描好的 PDF 自動比對到對應公文，改成統一檔名歸檔 |
| **資料庫設定** | 維護人員／部門／案類、變更密碼、跨年度重置、資源回收筒、備份還原；「系統設定」頁集中管理歸檔資料夾、簽收表標題、閒置時間、自動備份、陳報模式 |
| **操作紀錄** | 查誰在何時做了什麼（刪除、還原、登入失敗等），可篩選與匯出 |

> 💡 **交辦單 vs. 陳報**：交辦單是上級交辦下來、需要分派承辦人的公文；陳報是本單位主動向上呈報的公文。
>
> 💡 **歸檔**：把公文的掃描電子檔（PDF）依固定規則命名、收進指定資料夾，方便日後查找。
>
> 💡 **兩種陳報模式（可在「系統設定 → 陳報模式」切換）**：
> - **送文者輸入模式**（預設）：由送文者統一輸入案件，輸入時就填好陳報日期與發文人員。
> - **發文結算模式**：承辦人自己上系統陳報、先取得文號（暫不填發文資訊）；到了陳報日，送文者再到「簽收單列印」頁按一次**「結算發文」**，勾選要發的案件、補上發文日期與人員，即可直接印出簽收表。適合承辦人各自輸入、送文者集中發文的所內。（此模式可分別套用於刑案陳報、一般陳報、敘獎登錄與罰單登錄四項。）

**建檔長這樣**——上方填寫、下方即時預覽，確認無誤再送出：

![交辦單發文](docs/img/03-dispatch.png?v=1.2.7)

**歸檔不用手動改檔名**——選一份待歸檔的公文，右側會自動把資料夾裡「最像」的 PDF 排在前面，並標出符合的字數；確認後按歸檔，檔案就會被改成標準檔名收好：

![檔案歸檔，自動比對候選 PDF](docs/img/04-archive.png?v=1.2.7)

> 💡 **候選檔案的「符合 N 字」**：系統拿公文的日期、主旨、承辦人去比對 PDF 檔名，命中越多排越前面，幫你快速認出正確的檔案。

**簽收單一鍵產生**——選發文日期就排好整張表，可直接列印或存 PDF：

![簽收單列印預覽](docs/img/05-print-preview.png?v=1.2.7)

## 另一支：公文快速登錄系統

給**只需要登錄敘獎與罰單**的同仁用的輕量版程式（`Police-Entry-Manager.exe`）。畫面只有四個功能：**敘獎登錄、罰單登錄、資料庫瀏覽（只看敘獎與罰單）、系統設定（精簡）**。

<p align="center">
  <img src="docs/img/08-entry-menu.png?v=1.2.7" alt="公文快速登錄系統主選單" width="340">
</p>

- **和主程式共用同一份 `dbfile.db`**：在這裡登錄的資料，主程式立刻看得到，不需匯入匯出。
- **適合的場景**：承辦人各自登錄敘獎或罰單，發文與簽收表仍由送文者在主程式處理。
- **擺放方式相同**：把 `Police-Entry-Manager.exe` 和 `dbfile.db` 放在同一個資料夾即可；也可以和主程式放在一起共用同一份資料。

> 💡 **要用哪一支**：需要收文、陳報、歸檔、列印簽收表 → 用主程式。只登錄敘獎或罰單 → 用快速登錄系統，介面單純、不會誤觸其他功能。
>
> ⚠️ 簽收單列印（含結算發文）、檔案歸檔、備份還原與跨年度重置只有主程式有；敘獎或罰單若設為發文結算模式，結算要回主程式做。

## 快速開始

### 1. 下載

到 [**最新版下載頁**](https://github.com/jerrygskk/PoliceDocSys/releases/latest)，下載 **`PACKED.zip`**。解壓後包含四個檔案：`Police-Document-Manager.exe`（主程式）、`Police-Entry-Manager.exe`（快速登錄系統）、`dbfile.db`（空白資料庫）及 `create_shared_shortcuts.bat`（網路分享捷徑建立工具）。PACKED 內兩支程式使用固定英文檔名、不帶版號，避免從 SMB 網路分享啟動時發生中文檔名相容性問題。

> 也可以分開下載：`Police-Document-Manager_v版號.exe`（主程式）＋ `dbfile.db`（空白資料庫）。單獨下載的 EXE 以帶版號檔名提供；固定英文檔名與捷徑工具以 `PACKED.zip` 內容為準。

### 2. 擺放

把解壓出來的四個檔案放在**同一個資料夾**；資料夾名稱可自行決定，但伺服器、分享及資料夾名稱不可包含 `%`。

若放在 SMB 網路分享，管理者**在該資料夾執行一次 `create_shared_shortcuts.bat`** 即可，它會自動解析出網路路徑並建立「公文收發管理系統」及「公文快速登錄系統」兩支中文捷徑。其他電腦即使網路磁碟機代號不同，也能共用這兩支捷徑，不必逐台設定。

> 💡 三種擺法都可以：放在分享底下的資料夾（捷徑建在**上一層**，使用者不必再點進去）、直接放在分享根目錄（捷徑就建在**同一層**）、或從映射的網路磁碟執行。管理者**直接在伺服器本機**（例如 `D:\shares\公文系統`）執行也可以，工具會自動換算成網路路徑。
>
> ⚠️ 只有放在**網路分享**底下才有意義；放在自己電腦的一般資料夾執行會提示「不是網路路徑」——那種情況本來就直接雙擊 `.exe` 即可，不需要捷徑。

> ⚠️ 程式與 `dbfile.db` 必須在一起。兩支程式共用同一份 `dbfile.db`，不需要各放一份。`dbfile.db` 是你所有公文資料的所在，請當成重要檔案保管、定期另存備份。

### 3. 開啟與初次設定

放在本機資料夾時，雙擊 **`Police-Document-Manager.exe`** 即可使用；放在 SMB 網路分享時，請從 BAT 建立的「公文收發管理系統」中文捷徑開啟。日常的收發文、建檔、列印**不需登入**；但初次設定（以及日後的刪除管理、設定維護、操作紀錄）需要以管理身分登入：

- 進「**資料庫設定**」輸入密碼登入。預設密碼——管理者：`admin`、歸檔管理：`0000`。
- 登入後進「**人員管理／部門管理**」，把單位的人員與部門建好。
- 進「**系統設定**」，設定「**歸檔資料夾**」與「**簽收表標題**」兩項（步驟見下方）。

系統會依目前登入身分精簡上方分頁；「資料庫設定」分頁永遠保留作為登入入口。從主選單選擇目前隱藏的管理功能時，會直接前往登入畫面。

![從主選單選擇隱藏功能時，系統會引導至登入畫面](docs/img/09-role-tabs-login.png?v=1.2.7)

> ⚠️ **首次登入後請立即至「變更密碼」修改**，預設密碼僅供初次設定使用。變更成功後系統會自動登出，請以新密碼重新登入。

> 💡 **想先看操作圖解**？下載頁附有 **`Quick_Start` 速查卡**（兩頁 A4，檔名帶版本號），涵蓋每個功能的重點步驟。

### 設定歸檔資料夾

「檔案歸檔」與「資料庫瀏覽開啟 PDF」都依賴這項設定。到「**資料庫設定 → 系統設定 → 歸檔資料夾**」設定，重點是 **一個「本年度資料夾」底下放兩個分類子資料夾**：

![系統設定頁的歸檔資料夾區塊](docs/img/07-archive-folder.png?v=1.2.7)

1. **本年度資料夾**：按「選擇資料夾」，挑選本年度掃描 PDF 的存放位置。
2. **刑案子資料夾 / 一般子資料夾**：選好上層資料夾後，下方會自動列出它底下的子資料夾，分別指定哪個放刑案、哪個放一般（也可手動輸入名稱）。
3. 按「儲存」。

建議的資料夾結構（名稱可自訂）：

```
案件掃描檔\115年\        ← 步驟 1 選這層（本年度資料夾）
├─ 刑案\                 ← 指定為「刑案子資料夾」
└─ 一般\                 ← 指定為「一般子資料夾」
```

> 💡 **為什麼路徑會自動變成 `\\電腦名稱\…` 這種樣子**：若資料夾在共用網路磁碟（例如 `Z:`），程式會自動把磁碟機代號改寫成「網路路徑（UNC）」再儲存。因為每台電腦對映的代號可能不同（這台是 `Z:`、那台是 `Y:`），改存網路路徑後，每台電腦都能找到同一個資料夾。
>
> 💡 **網路路徑（UNC）**：以 `\\` 開頭、用電腦／伺服器名稱定位資料夾的寫法，例如 `\\PC-SERVER\案件掃描檔\115年`，不依賴磁碟機代號。

> ⚠️ 若路徑框出現**橘色外框**，代表選到的資料夾無法轉成網路路徑（例如選到本機 `C:` 槽）。自己一台電腦用沒關係；要給多人共用，請改放在共用網路磁碟上的資料夾。
>
> ⚠️ **沒設定會怎樣**：「檔案歸檔」無法比對、「資料庫瀏覽」開不了 PDF。另外，**跨年度重置後這項設定會被清空**，新年度要重新指定。

### 設定簽收表標題

簽收表標題裡的單位名稱，一開始先用「○○」代替（例如印成「○○分局交辦單簽收表」），用之前請改成自己的單位名稱。到「**資料庫設定 → 系統設定 → 簽收表標題**」（需管理者登入）就能改：

1. 六個欄位整句可編輯——**交辦單、刑案陳報、一般陳報、敘獎、罰單**五張表的標題，以及**現行犯免簽收註記**。
2. 把標題裡的 `○○` 改成自己的單位名稱（其餘文字也可整句自訂），按「儲存」。可按「恢復預設」帶入預設標題。

> 💡 **現行犯免簽收註記**：現行犯卷宗通常隨案移送，簽收表上這句備註用來提醒收案人本案無卷宗可供簽收。文字可整句自訂。

> ⚠️ 此設定屬單位永久設定，**跨年度重置不會清空**。

## 常見問題

**Q：不小心把公文刪掉了怎麼辦？**
刪除的公文會進「資源回收筒」（資料庫設定頁，需管理者登入），選取後按「還原」即可救回原本的文號與內容。

![資源回收筒](docs/img/06-recycle-bin.png?v=1.2.7)

**Q：資料會不會不見？**
程式每天開啟時會自動備份（按日、週、月三層輪替保留，最久涵蓋約一年），存在資料庫旁的 `backups` 資料夾。此外可到「**資料庫設定 → 系統設定 → 自動備份**」指定一個**異地備份位置**（例如另一顆網路磁碟或本機硬碟），程式會於下次開啟時一併備份一份到該處，防範整顆硬碟故障造成資料毀損。該位置請於程式開啟時保持可連線（讀寫）狀態；若為需要登入的網路位置，請於開啟過該位置時勾選「記住我的認證」。仍建議定期把整個資料夾另存到隨身碟或網路硬碟。

**Q：資料損毀或誤操作了，怎麼從備份救回？**
到「**資料庫設定 → 備份還原**」（需管理者登入），清單會列出本機備份、異地副本與歷次留底，選一份按「還原」即可覆蓋回目前資料庫。還原前系統會自動把目前資料另存留底、並檢查備份是否完好，完成後程式自動重新啟動。
若資料庫**嚴重損毀到程式無法開啟**，開啟時會直接跳出還原視窗，自動找出最近一份可用的備份，輸入管理者密碼即可還原。

**Q：可以多台電腦同時開同一份資料嗎？**
可以把資料庫放在共用網路磁碟給多人輪流使用。若有人已開啟，他人開啟時會跳出提醒。但**不建議多人同時編輯**，可能造成資料毀損——請輪流使用。

**Q：需要安裝、或連外部網路嗎？**
都不需要。程式免安裝、雙擊即用，也不需要連網際網路、不需要架設資料庫伺服器。所有資料就存在 `dbfile.db` 這一個檔案裡——可放在本機自己用，也可以放在單位內部的共用網路磁碟給多人輪流使用（見上一題）。

**Q：日期怎麼一直改不動？滾輪和方向鍵都沒反應。**
這是刻意的。日期欄只能用兩種方式修改：**直接輸入數字**（打完會自動跳到下一段），或**點右側月曆**翻頁挑選。滑鼠滾輪、方向鍵、PageUp／PageDown 以及點擊欄位都不會再改動日期——這些操作在填別的欄位時很容易誤觸，畫面上只有一個數字變動，登錄當下幾乎不會發現，等到印簽收表才發現那幾筆印不出來。

**Q：按送出時跳出「請確認日期」是怎麼回事？**
表示你填的發文日期與今天差距較大（早於今天，或晚於今天 10 天以上）。這只是提醒不是限制，確認無誤按「確認無誤」即可繼續，補登前幾天的公文屬正常情形。同一頁的同一個日期只會提醒一次；換到別頁登錄會再提醒一次（各頁分開計，避免某一頁的日期被誤改卻因為別頁確認過而靜默放行）。

**Q：搜尋區分大小寫嗎？**
不分大小寫，輸入片段即時比對。

**Q：閒置會怎樣？**
管理身分閒置一段時間會自動登出（降回一般使用者，預設 10 分鐘）；任何身分閒置過久程式會自動關閉（預設 14 分半）。自動關閉前會先在畫面上方顯示紅色倒數提醒，只要移動滑鼠或按任意鍵即可繼續使用。兩個時間都可在「**資料庫設定 → 系統設定 → 閒置逾時**」調整，設 0 表示不作用。

自動登出（與手動按登出）當下會**關閉所有開啟中的視窗，尚未按下確認的內容不保留**，離開座位前請先存檔。登出後如果目前這一頁一般使用者也能使用，會留在原頁；若該頁需要較高身分，會回到「資料庫設定」的登入畫面，輸入密碼後自動切回原本那一頁。

> 💡 **名詞速查**
> - **軟刪除**：刪除公文時只清空內容、保留文號，所以文號不會被重複使用（刪掉的那筆會標示「此文號無法再使用」）。
> - **跨年度重置**：新年度開始時，把所有公文清空、文號歸零重新計算的功能（屬管理者操作，執行前會自動備份）。
> - **承辦人 / 協辦**：負責處理該公文的人員；歸檔比對時會用來辨識檔案。
